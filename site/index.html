One binary, no runtime

Written in Rust. Linux, macOS and Windows. It needs only git on PATH.

Real updates

A three-way merge through git merge-file. Only edits that truly overlap become conflicts.

Nothing lost silently

Every case that needs a person is a conflict and exit code 2. CI only has to read the code.

How updates work

Your edits stay, the template's improvements arrive

The old and the new template versions are both rendered with the project's answers, and only the difference is merged into the project.
