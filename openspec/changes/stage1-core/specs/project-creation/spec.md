## ADDED Requirements

### Requirement: Команда new создаёт проект

`rootstock new <template> <dir>` SHALL создавать проект из шаблона на заданной версии (по умолчанию — последний semver-тег) и записывать `.rootstock.toml` (ТЗ: §Commands, §Concepts «Record»). `new` MUST быть обновлением из пустой базы в пустой проект (ТЗ: §How update works, последний абзац). Опции: `--version vX.Y.Z`, `--data k=v` (повторяемая), `--data-file`, `--defaults`, `--trust`, `--git`.

#### Scenario: Последняя версия по умолчанию
- **WHEN** в шаблоне есть теги `v1.0.0`, `v1.2.0`, и `new` вызван без `--version`
- **THEN** проект создаётся на `v1.2.0`

#### Scenario: Явная версия
- **WHEN** `new` вызван с `--version v1.0.0`
- **THEN** проект создаётся на `v1.0.0`, а в записи стоят этот тег и точный коммит

#### Scenario: Ответы заданы флагами
- **WHEN** все ответы переданы через `--data` или `--data-file`
- **THEN** вопросов не задаётся, ответы попадают в запись

### Requirement: Запись проекта

`.rootstock.toml` SHALL хранить номер версии схемы (ТЗ: §Left to the builder), источник шаблона, версию (тег и коммит), ответы и инвентарь — список выпущенных путей с классами (ТЗ: §Concepts «Record», «Inventory»). Ответы вопросов с ложным `when` MUST не записываться.

#### Scenario: Состав записи
- **WHEN** проект создан успешно
- **THEN** `.rootstock.toml` содержит источник, тег, коммит, ответы и пути с классами `managed` и `starter`

### Requirement: Источники шаблонов

Источником SHALL быть `https://…`, `git@…:…`, сокращение `gh:owner/repo` или локальный путь (ТЗ: §Commands, «Template sources»). Для локального пути версия — тег в этом репозитории; `--version HEAD` MUST рендерить рабочее дерево.

#### Scenario: Рабочее дерево шаблона
- **WHEN** `new ./tpl <dir> --version HEAD` вызван над локальным шаблоном с непроиндексированными правками
- **THEN** проект отражает правки рабочего дерева

### Requirement: Инициализация git

`new` MUST выполнять `git init` только если каталог пуст и задан `--git` (ТЗ: §Commands, `new`).

#### Scenario: Без флага git
- **WHEN** `new` вызван без `--git`
- **THEN** каталог `.git` не создаётся

#### Scenario: С флагом git в пустом каталоге
- **WHEN** целевой каталог пуст и задан `--git`
- **THEN** создаётся репозиторий git
