## MODIFIED Requirements

### Requirement: Предусловия обновления

`rootstock update` SHALL отказываться (код 1, ничего не записано), если в рабочем дереве есть незакоммиченные изменения (ТЗ: §How update works, п. 1). Целью MUST быть `--to` или последний semver-тег. Если проект уже на цели и ни один ответ не меняется, итог — код 0, ничего не делается (п. 2, 1.3). Ответ меняется, когда `--data` или `--data-file` задаёт значение, отличное от записанного.

#### Scenario: Грязное дерево
- **WHEN** в проекте есть незакоммиченные изменения
- **THEN** `update` завершается с кодом 1 и не меняет файлы

#### Scenario: Уже на целевой версии
- **WHEN** версия в записи совпадает с целью, а `--data` и `--data-file` не заданы
- **THEN** код 0, файлы и запись не меняются

#### Scenario: Тот же ответ на целевой версии
- **WHEN** версия в записи совпадает с целью, а `--data` задаёт ответ, равный записанному
- **THEN** код 0, файлы и запись не меняются

## ADDED Requirements

### Requirement: Смена ответа на текущей версии

Если проект уже на целевой версии, а `--data` или `--data-file` меняет хотя бы один ответ, `rootstock update` SHALL рендерить эту версию дважды: базу со старыми ответами, цель с новыми. Дальше идёт обычная таблица обновления, хуки обновления и новая запись (ТЗ: §Commands, `update`, 1.3; §How update works, п. 2). Версия и commit в записи MUST остаться прежними, ответы MUST стать новыми. Коды выхода — как у любого обновления.

#### Scenario: Смена ответа без смены версии
- **WHEN** проект на `v1.0.0`, цель `v1.0.0`, файл `README.md.jinja` выводит `{{ name }}`, а `update --data name=new` меняет ответ
- **THEN** `README.md` содержит `new`, запись хранит `name = "new"` и прежнюю версию, код 0

#### Scenario: Смена ответа убирает файл
- **WHEN** на текущей версии `update --data rust=false` выключает файл, которого проект не менял
- **THEN** файл удаляется, как при переходе на новую версию

#### Scenario: Правка проекта сохраняется
- **WHEN** проект правил файл, зависящий от ответа, а `update --data` на текущей версии меняет этот ответ
- **THEN** файл сливается трёхсторонне: при пересечении правок — маркеры и код 2
