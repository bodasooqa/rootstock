## MODIFIED Requirements

### Requirement: Права и симлинки

Бит исполнения SHALL следовать файлу шаблона; символические ссылки MUST воспроизводиться как ссылки и не разыменовываться (ТЗ: §How update works, п. 7). Бит и ссылка шаблона SHALL читаться из дерева git выгруженного commit'а (`100755`, `120000`), а не с диска; при рендере `HEAD` — из индекса, для неотслеживаемых файлов — с диска (1.4). Где у файловой системы нет бита исполнения (Windows), rootstock SHALL ставить бит в индекс git проекта, если проект — git-репозиторий, и читать бит проекта оттуда же (1.4). Если система отказывает в создании ссылки, команда MUST завершиться ошибкой до первой записи и назвать, как ссылки разрешить (1.4).

#### Scenario: Исполняемый файл
- **WHEN** файл шаблона исполняемый
- **THEN** выпущенный файл тоже исполняемый

#### Scenario: Симлинк
- **WHEN** в шаблоне лежит символическая ссылка
- **THEN** в проекте создаётся ссылка с той же целью, а не копия цели

#### Scenario: Бит из дерева, а не с диска
- **WHEN** файл в дереве шаблона записан как `100755`, а в выгрузке на диске он не исполняемый
- **THEN** выпущенный файл исполняемый

#### Scenario: Ссылка, выгруженная файлом
- **WHEN** ссылка в дереве шаблона (`120000`) выгружена обычным файлом с целью внутри (`core.symlinks=false`)
- **THEN** в проекте создаётся ссылка с этой целью

#### Scenario: Бит в индексе на Windows
- **WHEN** на Windows `new --git` выпускает исполняемый файл
- **THEN** в индексе git проекта у файла режим `100755`

### Requirement: Байты на входе — байты на выходе

Преобразования окончаний строк MUST не выполняться; слияние идёт по строкам, но SHALL сохранять окончания строк и завершающий перевод строки файла (ТЗ: §How update works, п. 8). Конфиг git пользователя (`core.autocrlf`) MUST не менять байты выгруженного шаблона.

#### Scenario: Файл с CRLF
- **WHEN** файл с окончаниями CRLF сливается без конфликта
- **THEN** результат сохраняет CRLF во всех строках

#### Scenario: Нет завершающего перевода строки
- **WHEN** файл без завершающего перевода строки сливается без конфликта
- **THEN** результат без завершающего перевода строки

#### Scenario: autocrlf пользователя
- **WHEN** в конфиге git пользователя `core.autocrlf=true`, а файл шаблона с окончаниями LF
- **THEN** выпущенный файл байт в байт совпадает с файлом шаблона
