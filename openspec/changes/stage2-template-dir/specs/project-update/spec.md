## ADDED Requirements

### Requirement: Подкаталог шаблона из записи

`update` и `status` SHALL брать шаблон из подкаталога, записанного в `.rootstock.toml`, без флага (ТЗ: §Commands, `--subdir`, 1.1). Базовый и целевой рендеры MUST читать один и тот же подкаталог. Если на целевой версии в нём нет `rootstock.toml`, `update` MUST завершаться с кодом 1, ничего не записав.

#### Scenario: Обновление шаблона из подкаталога
- **WHEN** проект создан с `--subdir tpl` на `v1.0.0`, а `v1.1.0` изменила файл в `tpl/`
- **THEN** `update` приносит изменение, а запись по-прежнему хранит подкаталог `tpl`

#### Scenario: Подкаталог исчез на целевой версии
- **WHEN** на целевой версии в записанном подкаталоге нет `rootstock.toml`
- **THEN** код 1, файлы и запись не изменены
